# Queen's Domain: reference project

The current harness was generalized from the owner's Italian Queen's Domain project.
This page records process and aggregates; it contains no game scripts, native keys,
translations, official references or private worker conversations.

## Automated linguistic workflow

The owner recorded Claude Opus 5.5 in Claude Code for initial source/context research,
style, glossary and character preparation, then GPT-6.1 Sol in Codex for translation
and the subsequent agent-managed quality stages. The orchestrator handled scheduling,
recovery, evidence-based decisions within explicit delegation, independent reviewer
contexts, resolved revisions, corpus consistency, Italian fluency and candidate QA.

The full scope contained 2,272 units. A 134-unit pilot was completed and assessed
before bulk work. Every changed version returned to independent bilingual review.
Approved preparation was reused; model names and different labels were not treated
as proof of independence or quality.

## Additional external review

The owner transported a private bilingual review kit through twelve AI Studio chats,
using the model they recorded as Gemini 4 Argon, and returned the results as text.
The linguistic judgments were generated by AI; this transport step was manual.

Codex assessed all 28 structured proposals plus 21 deduplicated notes against current
source, policy and context. Three targeted corrections were accepted; twenty-five
proposals were rejected with evidence. Three changed versions completed independent
bilingual rereview, resolved revision and local consistency/fluency. Unaffected work
was retained. This is the maintenance pattern documented in the current prompts.

The reusable pieces of this run are now part of the repository: see
[the orchestration guide](ORCHESTRATION.md), [the external review guide](EXTERNAL-REVIEW.md)
and [the example mapping](../examples/queens-domain/README.md).

## Evidence boundaries

The candidate completed offline QA, native identity/CRC checks, source-copy and
roundtrip checks, actual pak readback and applicable font/markup checks. Runtime and
harness release approvals remained pending at offline closure. The public beta's
publication is distinct from those gate decisions.

The [public mod repository](https://github.com/lorenfa99/queens-domain-traduzione-italiana)
credits the tools and methodology. Only reusable harness code, blank policies and
synthetic tests are included here. Game-specific corpus, policies, native assets,
checkpoints and research remain private.
