# Official reference policy

Source meaning and verified context govern the translation. When a referent,
mechanic, word sense or voice is uncertain, compare matching official versions.
Each reference must match snapshot, namespace, key and source revision. Exclude
pseudo-locales, stale/empty entries and source copies as independent evidence.

Record the question, languages actually read, material comparison, conclusion and
remaining uncertainty in `reference_checks`. Majority agreement does not resolve
a conflict. Preserve unknown gender, lore and chronology until evidence establishes them.
An unresolved question is an issue; it is never permission to invent a translation.
