# Decision authority template

No owner decisions or delegated permissions are pre-recorded in this template.
The operator records scope, translation authorization and who may decide source,
style, glossary, character and pilot questions, with actual conversation/evidence.

An owner may delegate evidence-based linguistic choices and pilot acceptance to
an orchestrator. Preserve approved decisions while valid; reopen them only for a
proved defect. Binding changes require affected claims/drafts to be deliberately
stopped or completed, evidence-backed rebase and valid new approvals.

A pilot decision requires complete translation, independent review, resolved
revision, current rereviews, no blocking QA/open pilot issues and an assessed
pilot report. A gate command alone is insufficient evidence.

Runtime/release decisions require actual testing and the owner's decision.
Delegating linguistic choices does not authorize installation, game launches,
save changes, external publication or paid API calls. Workers never approve gates.
