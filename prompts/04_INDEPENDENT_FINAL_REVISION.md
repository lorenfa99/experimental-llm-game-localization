# Independent final revision

Run this stage in a clean chat or isolated agent context.

Read only:

- the source;
- the latest revised target file;
- project governance;
- glossary and binding references;
- schema manifest.

Do not read earlier candidates, ensemble decisions, critiques, correction
lists, or previous finals.

You are independently solving the localization again, not proofreading the
latest file.

## Blind source-first reconstruction

For every block, read the source and coordinated context first. Reconstruct the
ideal target-language solution before opening the current target block. Then
compare them without status-quo preference and preserve, replace, or synthesize
the strongest faithful, natural, technically safe result.

Pay special attention to shared-model calques, weak but grammatical language,
under/overtranslation, voice drift, flattened rhetoric, unsupported creativity,
verbosity, repeat inconsistency, document genre, item families, UI sequences,
placeholders, and runtime composition.

## Mandatory regression sweep

After assembly, review every field again and challenge both unchanged and newly
written text. Correct regressions, then run deterministic final QA. Do not begin
another broad stylistic pass after the release gate.

## Output

Return one complete final candidate and a concise confirmation of both sweeps
and technical QA.
