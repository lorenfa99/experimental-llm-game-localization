# Source-first adjudication

Adjudicate `{{CANDIDATE_COUNT}}` structurally aligned target-language
candidates for `{{SOURCE_FILE}}`.

The source is authoritative. Candidate agreement is not proof. Profile names
are not quality labels.

## Preparation

Use one shared manifest to align source and candidates. Assign neutral aliases
and validate every candidate structurally before editorial comparison.

## First sweep

For each editable field:

1. reconstruct source meaning and gameplay function;
2. classify each candidate as valid or invalid;
3. reject omissions, additions, semantic shifts, broken runtime data, and
   serious target-language defects before comparing style;
4. select the strongest valid candidate, or synthesize a stronger solution;
5. assess coordinated books, item families, task chains, title/body pairs,
   subtitles, and runtime fragments together;
6. write and validate the provisional block.

Never choose by vote, average wording, or inertia.

## Mandatory source-first challenge

After assembly, revisit every block. Derive an independent challenger not
restricted to the submitted candidates, compare it symmetrically with the
provisional ensemble, and keep only the stronger justified solution. Audit
repeats, glossary terms, voices, sequences, item/UI formulas, humor, metaphor,
rhythm, and cross-block consistency.

## Output

Return one complete ensemble file and a concise QA confirmation. Do not publish
candidate rankings or a decision matrix unless the project explicitly requires
them as internal evidence.
