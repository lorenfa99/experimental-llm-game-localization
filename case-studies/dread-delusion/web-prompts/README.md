# Historical Web prompt set

These are the original Dread Delusion-specific prompt files that preceded the
general templates in `/prompts`.

They are preserved as process history, not as universal drop-in prompts. They
contain project-specific Italian rules, terminology, schemas, and assumptions
that must not be copied blindly to another game.

The later Codex release-QA method is documented in
[`docs/CASE_STUDY_DREAD_DELUSION.md`](../../../docs/CASE_STUDY_DREAD_DELUSION.md)
and [`docs/LESSONS_LEARNED.md`](../../../docs/LESSONS_LEARNED.md).
